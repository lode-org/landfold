* About

~landfold~ (Landscape And Nonlinear Distance Folding Onto Low
Dimensions) embeds high-dimensional molecular descriptors into a low-D
map by transforming pairwise distances with a generalised sigmoid and
minimising the mismatch (Ceriotti, Tribello, Parrinello, PNAS 2011,
DOI [[https://doi.org/10.1073/pnas.1108486108][10.1073/pnas.1108486108]]).

The default solver is full-pair Polak-Ribiere CG. Optional arms:
randomised pair search, Gram-matrix Euclidean distances.

* CLI

#+begin_src sh
landfold embed -D 30 -d 2 --fun-hd 6,8,8 --fun-ld 6,2,8 --steps 50 < hd.dat
landfold mds -D 30 -d 2 --distances < hd.dat
landfold fes --input ld.dat --svg fes.svg
