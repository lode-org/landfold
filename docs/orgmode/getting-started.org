* Build

Compile on a remote builder, not a laptop:

#+begin_src sh
cargo test --release
cargo build --release --bins
#+end_src

* C++ oracle goldens

Regenerate =tests/goldens/cpp_oracle.txt= on the remote builder from
HaoZeke/sketchmap =addLocks= (needs the valarray ostream fix in
=libs/tbdefs.hpp=):

#+begin_src sh
SKMAP_SRC=$HOME/Git/Github/HaoZeke/sketchmap \
  bash scripts/gen_cpp_goldens.sh
cargo test --release --test cpp_parity
#+end_src

The oracle links =libdimred.o= + =libtoolbox= and dumps f/df, pairwise
Euclid/PBC, Torgerson MDS pairwise distances of the private embedding
=p=, and =NLDRITERChi= χ/∇χ. =landfold mds --distances= prints the
same invariant (full matrix) from the Rust Torgerson path.

* Torgerson MDS

#+begin_src sh
landfold mds -D 30 -d 2 --distances < landmarks.dat > landmarks.mds.dist
#+end_src

* Embed

#+begin_src sh
landfold embed -D 30 -d 2 --fun-hd 6,8,8 --fun-ld 6,2,8 --steps 50 \
    --pi 6.283185 -w < landmarks.dat > landmarks.ld
#+end_src

* Project

#+begin_src sh
landfold project -D 30 -d 2 --high-file landmarks.dat --low-file landmarks.ld \
    --pi 6.283185 --fun-hd 6,8,8 --fun-ld 6,2,8 \
    --grid 60,51,501 --refine 3 < colvar.dat > colvar.ld
#+end_src

* Free-energy surface

#+begin_src sh
landfold fes --input colvar.ld --nx 80 --ny 80 --svg fes.svg --csv fes.csv
#+end_src
