* Build

Compile on a remote builder, not a laptop:

#+begin_src sh
cargo test --release
cargo build --release --bins
#+end_src

* Python feature

Optional CPython module (=embed_euclid=, =project_euclid=,
=farthest_euclid=, =fes_xy=). pyo3/numpy stay on 0.29 so the graph
shares one major with dlpk 0.4.1. Do not enable =dlpk/pyo3= (that
would add a second =pyo3-ffi= =links = "python"= edge).

#+begin_src sh
cargo tree -e features --features python
bash scripts/check_pyo3_pin.sh
cargo check --release --features python
#+end_src

=landfold --version= is the CLI binary and does not load the
extension. =Solver::Standard= stays the default full-pair CG.

* C++ oracle goldens

Regenerate =tests/goldens/cpp_oracle.txt= on the remote builder from
the HaoZeke =addLocks= C++ tree (valarray ostream fix in
=libs/tbdefs.hpp=, =$SKMAP_SRC=):

#+begin_src sh
SKMAP_SRC=$HOME/Git/Github/HaoZeke/sketchmap \
  bash scripts/gen_cpp_goldens.sh
cargo test --release --test cpp_parity
#+end_src

The oracle links =libdimred.o= + =libtoolbox= and dumps f/df, pairwise
Euclid/PBC, Torgerson MDS pairwise distances of the private embedding
=p=, =NLDRITERChi= χ/∇χ, one-point query χ, and Gonzalez
farthest-point indices. =landfold mds --distances= prints the same
invariant (full matrix) from the Rust Torgerson path.

* Torgerson MDS

#+begin_src sh
landfold mds -D 30 -d 2 --distances < landmarks.dat > landmarks.mds.dist
#+end_src

* Embed

#+begin_src sh
landfold embed -D 30 -d 2 --fun-hd 6,8,8 --fun-ld 6,2,8 --steps 50 \
    --pi 6.283185 -w < landmarks.dat > landmarks.ld
#+end_src

* Landmarks

Gonzalez farthest-point sampling (Gonzalez 1985,
DOI [[https://doi.org/10.1016/0304-3975(85)90224-5][10.1016/0304-3975(85)90224-5]]). =--seed= picks the first
index modulo N. =--indices= writes a =# indices ...= comment so the
point table stays readable by =read_points=. =--voronoi= replaces
the FPS scores with Voronoi masses (=--wgamma=).

#+begin_src sh
landfold landmarks -D 30 -n 200 --seed 1 --indices --voronoi \
    < hd.dat > landmarks.dat
#+end_src

* Project

A new high-D row is dropped onto the landmark map by a coarse then
fine χ grid on =[-gw, gw]^2=, optionally polished by =--refine=
Polak-Ribiere + Brent steps (Ceriotti, Tribello, Parrinello, JCTC 2013,
DOI [[https://doi.org/10.1021/ct3010563][10.1021/ct3010563]]). =--grid= is =gw,g1,g2=. =--print-error=
appends χ and the nearest-landmark HD distance.

#+begin_src sh
landfold project -D 30 -d 2 --high-file landmarks.dat --low-file landmarks.ld \
    --pi 6.283185 --fun-hd 6,8,8 --fun-ld 6,2,8 \
    --grid 60,51,501 --refine 3 < colvar.dat > colvar.ld
#+end_src

* Free-energy surface

=F/kT = -ln(ρ/ρ_max)= on a 2-D histogram (Ferrenberg and Swendsen,
PRL 1989, DOI [[https://doi.org/10.1103/PhysRevLett.63.1195][10.1103/PhysRevLett.63.1195]]). Empty bins are
=nan=. =--svg= is the heatmap; =--csv= is =x y F rho=. Optional
=--frames= plus =--cn-csv= writes the integer coordination histogram
used by the cluster-FES figure class. Bounds default to a 5% pad of
the data; pass =--xmin --xmax --ymin --ymax= to fix the box
(course LJ38 map: about =[-15,15]^2=). =--blur= is a separable
Gaussian of the counts; =--floor= keeps the largest connected body;
=--fmax= is the colour-scale clip (JCTC 2013 panel uses 2).

#+begin_src sh
landfold fes --input colvar.ld --nx 80 --ny 80 --kt 0.168 \
    --xmin -15 --xmax 15 --ymin -15 --ymax 15 \
    --blur 7 --floor 0.006 --fmax 2 \
    --svg fes.svg --csv fes.csv \
    --frames frames.xyz --cn-csv cn.csv --cn-cutoff 1.2 --cn-max 12
#+end_src

Energy on that plane is the MethodsX representation (potential
energy plus synthetic path-tangent gradients, then
=plot.representation.plot_energy=):

#+begin_src sh
rgpycrumbs landfold plot-energy --input cloud.energy.csv \
    --output energy.png --frame rmsd --method grad_imq
#+end_src

=--svg= is the occupancy heatmap. Occupancy publication figures go
through chemparseplot (=plot.landfold.plot_fes=):

#+begin_src sh
rgpycrumbs landfold plot-fes --input fes.csv --output fes.png \
    --kt 0.168 --fmax 2 --method grad_imq
#+end_src
