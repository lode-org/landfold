* About

~landfold~ (Landscape And Nonlinear Distance Folding Onto Low
Dimensions) is an MIT library for sigmoid-distance embedding of
high-dimensional molecular data (Ceriotti, Tribello, Parrinello, PNAS
2011, DOI [[https://doi.org/10.1073/pnas.1108486108][10.1073/pnas.1108486108]]).

* Tools

| Subcommand | Role |
|------------+------|
| =embed= | Torgerson MDS init + standard full-pair CG (or =--stoch=) |
| =project= | coarse then fine χ grid + =--refine= (JCTC 2013) |
| =landmarks= | Gonzalez farthest-point; =--voronoi= masses |
| =dist= | pairwise |
| =mds= | classical Torgerson MDS; =--distances= dumps the sign-invariant pairwise |
| =fes= | =F=-ln(ρ/ρ_max)= CSV/SVG + integer CN histogram |

Optional =--features python= is pyo3/numpy 0.29 (one major with dlpk
0.4.1). The packaged Chemparseplot bridge is installed with
=pip install 'landfold[chemparseplot]'=. See [[file:spec.org][spec.org]] and
[[file:getting-started.org][getting-started.org]].
