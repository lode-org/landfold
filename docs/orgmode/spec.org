* Transfer

Generalised sigmoid (Ceriotti 2011, DOI 10.1073/pnas.1108486108):

=F(x) = 1 - (1 + (2^{a/b}-1)(x/σ)^a )^{-b/a}=

equals 1/2 at =x = σ=.

* Stress

χ = (1/Z) Σ_{i<j} w_ij [ (1-imix)(F_HD(D_ij)-F_LD(d_ij))^2 + imix (D_ij-d_ij)^2 ]

* Solvers

| Arm | Method | Citation |
|-----+--------+----------|
| Standard (default) | Polak-Ribiere CG + Brent | Polak 1969; Brent 1973 |
| Stochastic | random pair mini-batches | Robbins and Monro 1951 |
| Anneal | Metropolis SA + CG polish | Kirkpatrick 1983 |
| Replica | parallel tempering + CG polish | Hukushima and Nemoto 1996 |
| HiGHS | L-BFGS two-loop projected by HiGHS | Huangfu and Hall 2018; Nocedal-Wright 7.4 |
| MDS init | Torgerson double-centre | Torgerson 1952 |

=Solver::Standard= is the published full-pair CG path. Halko rangefinder
MDS, stochastic pair search, and tensor/GEMM Euclid are extra arms and
are only kept after the C++ oracle match.

* C++ oracle

Goldens live in =tests/goldens/cpp_oracle.txt=, produced by
=scripts/gen_cpp_goldens.sh= against the HaoZeke =addLocks= C++ tree
(transfer f/df, pairwise Euclid/PBC, Torgerson MDS pairwise
distances, χ/∇χ, one-point χ of a query, Gonzalez farthest-point
indices). The C++ embedding coordinates are private, so the MDS
block is the i<j Euclidean distances of that embedding, not the
coordinates.

=tests/cpp_parity.rs= loads that file. A missing file is a hard fail.
A 1e-8 shift of any compared golden is outside the match tolerance.

* Package shape

Single package, one =landfold= binary. =clap= is a package dependency
because Cargo cannot mark a dep bin-only without a workspace split
(=landfold-w1p0=). The library API does not use clap.

* Python pin

=--features python= pulls =pyo3= and =numpy= 0.29, the same minor as
dlpk 0.4.1. dlpk's optional =pyo3= feature stays off: =pyo3-ffi= is
=links = "python"=, so a second pyo3 major cannot coexist. Bump
landfold only when dlpk publishes a graph that still resolves to one
pyo3 major.

Verify on the remote builder:

#+begin_src sh
bash scripts/check_pyo3_pin.sh
# cargo tree -e features --features python
#+end_src

The CLI binary does not link pyo3. =landfold --help= records the pin.
=Solver::Standard= remains the default full-pair CG for =embed=.

* Landmarks

Gonzalez farthest-point (2-approximate k-center) traversal. Seed
index = seed rem N. Optional per-point weights multiply the
min-distance score. =--voronoi= replaces those scores with Voronoi
masses raised to =wgamma=. Citation: Gonzalez, *Theor. Comput. Sci.*
**38**, 293 (1985), DOI 10.1016/0304-3975(85)90224-5.

* Project

Out-of-sample placement minimises χ of the query against the
landmarks (Ceriotti, Tribello, Parrinello, *J. Chem. Theory Comput.*
**9**, 1521 (2013), DOI 10.1021/ct3010563). For 1-D and 2-D embeddings
the search is a coarse grid of =g1= points on =[-gw, gw]^d= then a
fine grid of =g2= points in the winning cell, then =--refine=
Polak-Ribiere + Brent steps on the one-point χ. =grid_coarse < 2=
falls back to the nearest landmark. =--print-error= appends χ and
the nearest-landmark HD distance. Default solver for the parent
embedding remains =Solver::Standard= (full-pair CG).

* FES

=F/kT = -ln(ρ/ρ_max)= on a 2-D histogram of the embedding
(Ferrenberg and Swendsen, *Phys. Rev. Lett.* **63**, 1195 (1989),
DOI 10.1103/PhysRevLett.63.1195). Empty bins stay empty (=None= /
=nan=). CSV columns are =x y F rho=. SVG is a cell heatmap with an
=F/kT= bar, darker at low F. Optional Gaussian blur of the counts,
=floor= of ρ_max to keep one connected body, and clip to =fmax=
match the JCTC 2013 panel class.

Coordination numbers of Cartesian frames (neighbours inside a cutoff)
are the extra panel of that figure class. =landfold fes --frames
--cn-csv= writes integer bins =0..=cn-max=.
